# full-stack-sandbox
This is just a sandbox for me to play around with some styles using React and TypeScript. It can be used by any other developers to play around with React, TypeScript, Node.js, Django, and postgres. 

If you want to run this app you will need to install npm and have a postgres database created. There are no migrations or seeders for the database so part of your exploration could be adding seed values!  

In order to run the app locally the following commands after starting your postgres server. 

'''
# In the root level of this project
npm install

# start node backend
cd updates-engine  
npm install  
npm run dev  

cd ..  

# start react frontend  
cd react-client  
npm install  
npm run dev  
'''
